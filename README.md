# Wattbuch Neu

Neubau von Wattbuch auf dem Branch `neubau`: Rollentraining als Runde in einer 3D-Welt, für den Mac. Die bisherige App liegt unverändert auf `main`.

```bash
npm install
npm run app:sim   # ansehen mit simulierter Rolle
npm test          # Fehlercheck, Logik- und App-Tests
```

Aufbau, Regeln und Stand stehen in `CLAUDE.md`, der abgenommene Entwurf in `entwurf/`.
